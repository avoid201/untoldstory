# 🎮 Untold Story - Gameplay Guide

## 🚀 Erste Schritte

### 1. Spiel starten
```bash
python3 main.py
```

### 2. Erste Monster fangen
- **Fleisch verwenden** in Kämpfen
- **Schwächere Monster** zuerst fangen
- **Verschiedene Typen** sammeln

### 3. Talente lernen
- **Level aufsteigen** für neue Talente
- **Typ-spezifische Talente** wählen
- **Passiv-Fähigkeiten** aktivieren

## ⚔️ Battle-System

### Grundlagen
- **Turn-based Combat** - Abwechselnd angreifen
- **Type-Effectiveness** - Typen haben Vor-/Nachteile
- **Status-Effekte** - Brennen, Vergiftung, etc.
- **Meat-Taming** - Monster fangen

### Strategien
- **Type-Matchups** beachten
- **Status-Effekte** nutzen
- **Passiv-Fähigkeiten** aktivieren
- **Talent-Upgrades** planen

## 🎯 Talent-System

### Talent-Kategorien
- **Feuer** - Angriffs-Talente
- **Wasser** - Defensiv-Talente
- **Pflanze** - Heilungs-Talente
- **Körperlich** - Stärke-Talente
- **Geistig** - Magie-Talente

### Talent-Tiers
- **Tier I** - Level 1-10
- **Tier II** - Level 15-25
- **Tier III** - Level 30-40

### Passiv-Fähigkeiten
- **Feuerresistenz** - Reduziert Feuer-Schaden
- **Wasserresistenz** - Reduziert Wasser-Schaden
- **Körperkraft** - Erhöht Angriff
- **Widerstandsfähigkeit** - Erhöht Verteidigung

## 🎮 Controls

### Bewegung
- **WASD** oder **Pfeiltasten** - Laufen
- **Shift** - Sprinten
- **Leertaste** - Interagieren

### Battle
- **1-4** - Move auswählen
- **Tab** - Monster wechseln
- **Escape** - Menü öffnen

### Menü
- **Enter** - Bestätigen
- **Escape** - Zurück
- **Tab** - Zwischen Optionen

## 🐛 Troubleshooting

### Häufige Probleme
